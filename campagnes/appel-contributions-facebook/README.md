# Diffusion Facebook — appel à contributions

Ce dossier contient les exports prêts à publier et leur source HTML reproductible.

## Formats

- `portrait-4x5/` : carrousel principal en 1080 × 1350 px, cinq slides ;
- `carre-1x1/` : variante carrée en 1080 × 1080 px, cinq slides ;
- `appel-contributions-facebook-1200x630.png` : visuel unique pour un partage avec lien.

Ordre du carrousel : ouverture, formats proposés, première prise de contact, déroulement, coordonnées.

## Texte proposé

Vous travaillez sur la Nouvelle-Calédonie ou le Pacifique ? Vous avez une analyse, des données, une carte, une datavisualisation ou des résultats de recherche à partager ?

contours.nc est ouvert aux contributions extérieures.

Quelques lignes suffisent pour présenter votre idée, ce que vous souhaitez montrer et les sources mobilisées. Le format peut ensuite être discuté et adapté au site.

Découvrir la démarche : https://contours.nc/contribuer/

Écrire : contributions@contours.nc

## Textes alternatifs

1. Appel de contours.nc aux personnes travaillant sur la Nouvelle-Calédonie ou le Pacifique pour proposer une contribution extérieure.
2. Cinq formats possibles : note de recherche, carte ou datavisualisation, éclairage, données et méthodes, travail issu d’un mémoire, d’une thèse ou d’un stage.
3. Informations suffisantes pour un premier échange : sujet, résultat à montrer, sources mobilisées et lien éventuel vers un travail existant.
4. Quatre étapes : proposition, échange, préparation et relecture, puis publication avec une signature clairement identifiée.
5. Coordonnées pour proposer une contribution : contributions@contours.nc et contours.nc/contribuer/.
