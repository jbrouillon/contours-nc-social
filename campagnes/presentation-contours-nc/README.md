# Campagne — Présentation de contours.nc

Sept écrans de présentation du carnet (créés le 4 octobre 2026) : ce qu’est contours.nc, les thèmes explorés, la démarche, les formats, la promesse de nuance et l’appel à lire. Pas de source HTML dans ce dépôt : les exports sont livrés tels quels.

- `portrait-4x5/` : 1080 × 1350, carrousel Instagram et Facebook ;
- `carre-1x1/` : 1080 × 1080.

Usage : premier carrousel du compte Instagram (ouvert en octobre 2026).

## Texte proposé (Instagram)

Bienvenue sur contours.nc 👋

Un carnet de recherche et de datavisualisation consacré à la Nouvelle-Calédonie et au Pacifique : des cartes pour voir où se jouent les écarts, des données publiques pour partir de faits vérifiables, les sciences sociales pour replacer les chiffres dans leur contexte.

Territoires, élections, population, inégalités : toujours avec des sources citées, des méthodes explicites et les limites visibles.

Articles, cartes et méthodes : lien en bio.
